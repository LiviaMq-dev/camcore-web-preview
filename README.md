# CamCore — prévia web

Prévia navegável das telas do [CamCore](https://github.com/mmmaryae/capacete): página inicial, câmera e relatórios.

Esta versão estática serve para apresentar o design no GitHub Pages. Detecção por IA, autenticação, banco de dados, webcam e exportação de relatórios dependem do servidor Flask e não estão ativos nesta prévia.

Projeto acadêmico em equipe. Código original: https://github.com/mmmaryae/capacete
